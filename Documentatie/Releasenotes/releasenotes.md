# Releasennote 0.0.1 (27 november 2026)
In deze versie van de BGT Bevraging API is de volgende functionaliteit gespecificeerd:

* Het opvragen van actuele BGT object voorkomens met een lijst van object identificaties en evt. een indicatie of beëindigde objecten al dan niet geleverd moeten worden.
* Het opvragen van BGT object voorkomens met een lijst van object identificaties en evt. een regisatie van en/of registratie tot datume en tijd.
* Het opvragen van actuele BGT object voorkomens binnen een bepaald gebied (bounding box, polygoon of multipolygoon) evt. met een lijst van gewenste BGT object types en een indicatie of beëindigde objecten al dan niet geleverd moeten worden.
* Het opvragen van BGT object voorkomens binnen een bepaald gebied (bounding box, polygoon of multipolygoon) en evt. een regisatie van en/of registratie tot datume en tijd en/of een lijst van gewenste BGT object types.
* Het opvragen van de actuele toestand van een specifiek BGT object.
* het opvragen van de voorkomens van een specifiek BGT object.
* Het opvragen van een specifiek voorkomen van een specifiek BGT object.
* Het opvragen van de (de status van de verwerking van) een specifieke bevraging.
* Het opvragen van het resultaat (bestand) van een specifieke bevraging.
