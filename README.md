# bgt-bevraging-api
De BGT Bevraging API is bedoeld om BGT object gegevens op te vragen uit de landelijke voorziening basisregistratie 
grootschalige topografie (LV BGT) en deze te muteren of om een bronhouder registratie mee bij te werken. 

Via dit platform wordt de technische informatie omtrent de BGT Bevraging API beschikbaar gesteld.
Zie voor de laatste ontwikkelingen de informatie onder [Releasenotes](https://github.com/kadaster/bgt-bevraging-api/blob/concept-OAS/Releasenotes).

Raadpleeg voor meer informatie over de BGT API de pagina [BGT Bevraging API](https://www.kadaster.nl/zakelijk/registraties/basisregistraties/bgt/bgt-producten) op de website van het Kadaster.

Wilt u gebruikmaken van de BGT Bevraging API, vraag dan door middel van [dit formulier](https://formulieren.kadaster.nl/aanvraag_bgt_bevraging_api_productie) een API Key aan.

Om u als gebruiker op weg te helpen bij de implementatie van de BGT Bevraging API is het Getting Started bestand beschikbaar gesteld. Hierin is de belangrijkste informatie opgenomen over de BGT Bevraging API.

__Contact__

Heeft u vragen over de BGT Bevraging API of wilt u een bug of verbetering melden, dan kunt u een issue aanmelden in deze repository of contact opnemen via het [Contactformulier](https://formulieren.kadaster.nl/contact_bgt).
